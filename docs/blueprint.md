# **App Name**: DASH: Digital Access Security Hub

## Core Features:

- Dashboard Display: Central dashboard to display relevant information.
- Title Placement: Prominent display of the 'DASH' title at the center of the dashboard.
- Account Creation: Account creation using Supabase.
- OTP Login: Login using 6-digit OTP (One-Time Password) via Supabase.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) to evoke a sense of trust and security. This color suggests stability and reliability, suitable for a security-focused application.
- Background color: Very light indigo (#E8EAF6) to maintain a consistent look that isn't too dark and overpowering.
- Accent color: Vivid purple (#9C27B0), slightly analogous to the primary color, will draw attention to important actions and status updates without disrupting the harmony.
- Font pairing: 'Space Grotesk' (sans-serif) for headers, to give a modern feel. 'Inter' (sans-serif) for the body to provide clean and readable content.
- Centered title 'DASH' with other page elements arranged in a clear and intuitive layout.
- Subtle transition animations when the page loads or the content updates.
